# 0010. Is one consolidated markdown file per report the canonical format?

- **Status:** decided (existing practice; to be written up)
- **Date raised:** 2026-10-03 · **Date decided:** existing practice
- **Decided by:** Rufus
- **Beads:** reportsthatmatter-0z1o (post explaining why), i8en (annotations; see 0002)

## Decision

Each report is one version-controlled `full.md` with stable paragraph ids, built from pinned sources, from which the site and other outputs render. Why this beats HTML or PDF (diffable corrections, citable ids, one searchable file, independence from any renderer, provenance) is to be written up as a post with diagrams (0z1o).
